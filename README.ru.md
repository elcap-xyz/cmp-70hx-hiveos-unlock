# Разблокировка CMP 70HX для майнинга в HiveOS

[English version](README.md)

> **Назначение.** В репозитории собрана известная рабочая схема разблокировки CMP 70HX для майнинга в HiveOS: нужные версии, требования, порядок установки, проверка и контроль работы. Это **не** инструкция по прошивке VBIOS и она не добавляет физические видеовыходы.

## Известные рабочие версии

В рабочей установке использовалась строго эта комбинация:

| Компонент | Нужная версия / значение |
| --- | --- |
| Ядро HiveOS | `6.6.0-hiveos` |
| Драйвер NVIDIA | `610.43.03` |
| Тип модуля NVIDIA | Open Kernel Modules |
| Патч разблокировки | `0014-cmp70hx-ga104-rejoin14.patch` |
| Маркер успешной загрузки | `PASS_CMP70HX_RUNNING` |
| Майнер после проверки | WildRig |

Не подменяй эту связку более новым драйвером, другой веткой NVIDIA, сборкой с proprietary-модулями или патчем для другого ядра. Здесь версии работают только вместе.

## Что нужно до установки

- Риг с CMP 70HX, которым ты владеешь или имеешь право администрировать.
- HiveOS с уже загруженным точным ядром `6.6.0-hiveos`.
- Исходники NVIDIA Open Kernel Modules строго версии `610.43.03`.
- Проверенный файл патча `0014-cmp70hx-ga104-rejoin14.patch`, созданный для этих же исходников.
- Совпадающие с ядром заголовки и инструменты сборки на самом риге.
- Доступ к ригу после перезагрузки: панель HiveOS, локальная консоль или SSH.
- Резервная копия рабочей конфигурации перед заменой драйвера.

В репозитории пока нет исходников NVIDIA и самого патча. Нельзя брать патч с непроверенного сайта. Чтобы инструкция стала полностью воспроизводимой одной командой, добавь в `patches/` проверенный патч с контрольной суммой, а в `scripts/` — оригинальный сценарий его сборки.

## Проверка перед началом

Выполни на риге и сохрани результат рядом с заметками об установке:

```bash
uname -r
lspci -Dnn | grep -i nvidia
nvidia-smi -L
modinfo -F version nvidia
```

Продолжай только если текущее ядро и исходники/патч драйвера полностью совпадают с версиями выше. Если карта не определяется или уже загружен другой драйвер — остановись.

## Порядок установки

1. На время установки отключи автоматические изменения для этого рига. В частности, не запускай `nvidia-driver-update` и не обновляй HiveOS.
2. Помести на риг проверенные исходники NVIDIA Open Kernel Modules `610.43.03` и `0014-cmp70hx-ga104-rejoin14.patch`.
3. Примени патч только к чистому дереву точно совпадающих исходников.
4. Собери модуль на **этом же риге** и для загруженного сейчас ядра `6.6.0-hiveos`. Не копируй с другой машины готовый `nvidia.ko`.
5. Установи сборку по оригинальной процедуре из проверенного комплекта исходников.
6. Перезагрузи риг, когда установка завершится без ошибок.

Для точных команд сборки нужен исходный комплект патча и его сценарий установки. В этой инструкции намеренно нет выдуманных команд и непроверенного патча: ошибочный модуль NVIDIA может оставить риг без рабочего драйвера.

## Проверка разблокировки перед майнингом

После перезагрузки выполни:

```bash
dmesg -T | grep -E 'PASS_CMP70HX_RUNNING|NVRM|nvidia' | tail -100
nvidia-smi -L
nvidia-smi --query-gpu=name,driver_version,pstate,power.draw,temperature.gpu,utilization.gpu --format=csv,noheader
```

Ожидаемый результат:

- в логе ядра есть `PASS_CMP70HX_RUNNING`;
- `nvidia-smi` видит `NVIDIA CMP 70HX`;
- показана версия `610.43.03`, а под нагрузкой карта переходит в состояние `P0`.

Только после этого запускай WildRig или другой уже настроенный майнер и проверяй стабильность хешрейта, температуры, потребления и принятых шар.

## Известный рабочий профиль

На одной CMP 70HX зафиксирован примерно такой результат на PearlHash: **43.04 TH/s**.

| Параметр | Зафиксированное значение |
| --- | --- |
| Power Limit в HiveOS | 205 W |
| Фактическое потребление | около 178 W |
| Частота ядра | около 1455 MHz |
| Температура GPU | около 68 °C |
| Вентилятор | около 83% |

Это ориентир для одной карты, майнера и температуры помещения, а не универсальный разгон. Меняй один параметр за раз и следи за температурой, потреблением, rejected shares и сообщениями драйвера.

## Неполадки именно с разблокировкой

| Симптом | Что проверить |
| --- | --- |
| Нет `PASS_CMP70HX_RUNNING` | Точное ядро, версию Open Modules, патч и чистый лог сборки. |
| `nvidia-smi` не видит карту | Определение PCI, загруженный модуль NVIDIA и свежие строки `NVRM` в `dmesg`. |
| Драйвер перестал работать после обновления | Верни связку `6.6.0-hiveos` / `610.43.03`; не смешивай компоненты. |
| Нестабильный хешрейт | Верни консервативные частоты, проверь питание/температуру и лог майнера. |

## Важно

- Не прошивай VBIOS в рамках этой процедуры.
- Не публикуй закрытые данные пула, кошелька, удалённого доступа или конфигураций.
- Не распространяй непубличные исходники NVIDIA и патчи без разрешения.
- После стабильного запуска сделай одну контрольную перезагрузку, чтобы убедиться: модуль корректно загружается автоматически.
